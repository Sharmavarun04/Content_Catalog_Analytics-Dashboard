### Methodology

#### 1\. Data Ingestion

Raw content dataset was loaded into Power Query.

#### 2\. Data Cleaning

Data types, text inconsistencies, dates, durations and categorical values were standardized.

#### 3\. Transformation

Duration was separated into value and unit.
Rating information was transformed into broader audience groups.
Date attributes were prepared for time-based analysis.

#### 4\. Data Modeling

A relational Excel Data Model was created using the main content table and supporting dimensions.

#### 5\. Analytical Layer

Reusable DAX measures were created for title counts, content type distribution and share calculations.

#### 6\. Dashboard Layer

PivotTables, Pivot Charts, slicers and timeline controls were used to create the interactive dashboard.

#### 7\. Advanced Excel Logic

Dynamic-array functions were used for Top-N analysis and title-level analytical outputs.

#### 8\. Title Exploration

A Data Validation-based title selector was created to retrieve title metadata using XLOOKUP.

#### 9\. Validation

The workbook was tested after refresh across multiple slicer combinations and title selections.
